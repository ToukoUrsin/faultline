OPEN THE BLACK BOX

A small model.
Explicit assumptions.

Useful for learning and reasoning about failure.
Not a prediction of a production network.

01

Shortest available path

Dijkstra routing runs at every node. Edge cost is serialization plus propagation; current queue length does not influence route selection.

02

Finite, separate queues

Each link direction has a FIFO transmitter. Capacity includes the packet in service. Tail-drop rejects a packet when that queue is full.

03

Failure has a precise edge

Links fail permanently at their scheduled time. Waiting and in-flight packets are lost. Failure at the exact arrival time wins. Routing changes instantly.

04

Reproduce every result

No randomness, network calls or wall clock in the engine. Export the topology, parameters and complete trace. Reimport to run it again.
