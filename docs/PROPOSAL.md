# Faultline — 原创 MoonBit/WASM 网络故障实验室

**目标。** 帮助学习者和工程师理解网络故障、有限队列和时序之间的因果关系。常见拓扑图展示连接，但隐藏分组在故障发生前后所经历的具体事件。Faultline 将每个分组的注入、等待、传输、到达和丢弃连成可检查的轨迹，并提供严格控制变量的对照实验。

**实现。** 以 MoonBit 编写可复用离散事件仿真核心，包括确定性调度、Dijkstra 路由、按方向隔离的 FIFO 队列、容量限制、永久链路故障、跳数预算和统计。附加 MoonBit 分析模块执行故障时间参数扫描，并通过 BFS 枚举原始图的单链路与双链路包含极小割。数值 ABI 编译为没有宿主导入的 WebAssembly，浏览器 JavaScript 负责展示和交互。没有 JavaScript 仿真替代、云端调用或模型生成的事件。

**可演示成果。** 默认场景在 52 ms 发生桥接链路故障，12 个分组中 9 个送达，3 个丢失；健康对照全部送达。选择 P03 可以逐步检查它在 16、34、52 ms 的事件。25 次真实仿真的时序曲线展示「故障更早反而可能损失更少」的现象。瞬时突发场景区分拓扑健康与容量不足。用户可应用分析得到的最小割、调整条件、回放/拖动时间、导出完整实验，并在导入时重新计算。

**验证与边界。** 15 项 MoonBit 测试加真实 WASM 集成检查覆盖手算结果、边界时刻、排队故障、非法输入、确定性和守恒、参数扫描与最小割。核心限制 24 节点、64 链路、128 分组、96 跳。明确不实现 TCP、重传、真实抓包、路由收敛或生产网络预测。性能面向小型可解释实验，而非大规模网络仿真。
