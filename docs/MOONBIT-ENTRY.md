# MoonBit September 2026 — verified facts and exact gates

Checked September 21, 2026 against [the official bilingual event site](https://moonbitlang.github.io/Hackathon2026/) and its own linked destinations. The current site says the competition takes place online and is open to all developers, students and professionals. Its acceptance/registration date is **September 30**, superseding directory listings that say September24. No exact time or timezone is published on the accessible page. For planning, finish before September30 begins in China; this is a conservative internal target, not an official cutoff.

The main implementation language must be MoonBit. An original project, credited port, or substantive new work on an existing project can qualify. Requirements include a publicly accessible repository, continuous traceable commits, clear README, runnable examples, necessary tests, a recognized open-source license, and source attribution. AI can assist generation/design/tests/docs, but the entrant must understand technical decisions and accept responsibility for quality. Duplicated entries, split projects and trivial modifications are excluded.

The monthly new-project route requires an application with entrant details, public repository and a one-page project explanation. Eligibility is reviewed on a rolling basis before development/acceptance. Accepted monthly projects enter the quarterly pool. The separate community-maintenance route covers existing ecosystem contributions. Monthly support is RMB150 startup plus RMB350 completion; the quarterly first prize is RMB12,000. These are separate adjudicated awards, not guaranteed payouts.
